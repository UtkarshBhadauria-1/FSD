# 🌄 Backroads — Travel Website

A responsive travel website showcasing destinations, tour packages, and travel services — built with React.js and Tailwind CSS.

> **Status:** 🚧 In Progress — frontend is functional; backend and full MERN integration coming next.

## 🔗 Live Demo
_Coming soon_

## ✨ Features
- Responsive landing page with Hero, About, and Services sections
- Tour packages showcase
- Component-based architecture (Navbar, Hero, About, Services, Tours, Footer)
- Clean, mobile-friendly UI built with Tailwind CSS

## 🛠️ Tech Stack
**Frontend:** React.js (Vite), Tailwind CSS, JavaScript, HTML5, CSS3
**Planned:** Node.js, Express.js, MongoDB (for backend booking/inquiry functionality)

## 🚀 Getting Started

Clone the repo and run the frontend locally:

```bash
git clone https://github.com/UtkarshBhadauria-1/Backroads-Travel-Website-.git
cd Backroads-Travel-Website-/backroads-react
npm install
npm run dev
```
